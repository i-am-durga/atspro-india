## 🌐 1-Minute Zero-Cost Deployment

### Method 1: GitHub Pages (100% Free Forever)
1. Go to your repository on GitHub (`i-am-durga/atspro-india`).
2. Click **Settings** > **Pages** (left sidebar).
3. Under **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**. Your site will be live at:
   `https://i-am-durga.github.io/atspro-india/`

### Method 2: Vercel (100% Free, Custom Domain)
1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **Add New Project** and select `atspro-india`.
3. Click **Deploy**. Your site is live in 15 seconds with global CDN and SSL.
